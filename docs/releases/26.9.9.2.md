# ryan-culverts 26.9.9.2

Released locally for packaging and integration testing on 2026-09-09. This remains an
alpha package and is not engineering design software.

## Packaging changes

- `package.bat` now advances the normalized `yy.m.d.vv` calendar version automatically.
- An explicit newer version may be supplied with `--version`.
- CI builds the declared version with `--no-bump`.
- New wheels are built and verified in temporary storage before replacing the previous
  project distribution under `dist/`.
- Failed builds and verification retain the previous wheel and restore `pyproject.toml`.
- Focused tests cover calendar rollover, invalid versions, rollback, and safe promotion.

## Engineering scope

Hydraulic calculations and their acceptance boundary are unchanged from version
`26.9.9.1`. Review `docs/computational_basis.md`, `docs/validation.md`, and the prior release
notes before interpreting results.

## Installation

Use the maintained installer so it selects the sole current wheel:

```powershell
.\install-latest-wheel.bat
```
