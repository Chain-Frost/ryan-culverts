# ryan-culverts 26.9.9.1

Released locally for packaging and integration testing on 2026-09-09. This is the first
packaged alpha milestone. It is not engineering design software and has not been published
to a package index.

The release artifact is the pure-Python `py3-none-any` wheel for Windows, Linux, and macOS.
Python 3.14 is the only tested interpreter baseline. No source archive is produced.

## Included capability

- Typed SI geometry and hydraulic primitives for circular and rectangular culverts.
- Critical depth, normal depth, HDS-5 inlet-control branches, full-flow losses, and
  supported direct-step outlet-control profiles.
- Provisional barrel, identical-barrel group, mixed-group crossing, rating-curve, and
  road-level inventory calculations.
- Structured convergence records, adopted coefficient and roughness provenance, hydraulic
  warnings, and applicability notices.
- Analytical, primary-source, conservation, regime-transition, and version-pinned HY-8
  comparison evidence described in `docs/validation.md`.

## Evidence boundary

Python 3.14 is the tested baseline. The package metadata permits other Python 3 versions
to attempt installation, but they are not supported until tested. HDS-5 and independently
calculated fixtures are the calculation evidence; HY-8 8.0.1.2 is comparison evidence and
does not define correctness.

The combined solver remains provisional. The retained Type 6 high-head inlet difference
and long-barrel crown-transition difference are documented method differences, not values
tuned to HY-8. Review `docs/computational_basis.md` and `docs/validation.md` before
interpreting results.

## Known limitations

- No roadway overtopping, reverse flow, adverse-slope calculation, or connected hydraulic
  network model.
- No design-option search, uncertainty analysis, plotting, GIS integration, or versioned
  JSON/spreadsheet interface.
- Supported shapes, inlet configurations, materials, and profile families are deliberately
  limited; unsupported cases fail closed or retain explicit warnings.
- Corrected modern box-inlet coefficients require the typed physical context deferred to
  CS-013. NCHRP 734 refinements remain deferred to CS-014.
- Some free-surface paths do not calculate separate scalar loss components, interpolation
  fallbacks have no fabricated root record, and full-flow results do not include calculated
  longitudinal profile points.

## Installation

Install the built wheel into a clean target or environment rather than over an editable
development installation:

```powershell
python -m pip install dist/ryan_culverts-26.9.9.1-py3-none-any.whl
```
